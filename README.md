# derya-neolab

The public Derya website: a home page (`app/page.tsx`), Vision, Principles and About pages, and an engraved sea (`app/components/sea.tsx`). A second version styled as a Bell Labs terminal lives under `app/bell/` (served at `/bell/`). Both read their copy from `app/content.ts`. Every push to main deploys to GitHub Pages (`.github/workflows/pages.yml`).

```
npm install
npm run dev
```
